# GitHub Projects (vistas por rol)

1. En el **Project**, crea una **vista guardada** por cada `role-*` que uses a diario, con filtro `label:role-backend` (o el que corresponda).
2. Columnas sugeridas: **Backlog → Ready → In progress → In review → Done** (ajusta a tu proceso).
3. **WIP:** intenta **una** tarjeta en *In progress* por rol cuando trabajas solo.

Mas contexto de labels y tableros: [ticket-taxonomy.md](./ticket-taxonomy.md).
